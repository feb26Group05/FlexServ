# FlexServ

FlexServ is a full-stack service booking and management platform that connects customers with professional service providers through a seamless digital experience. The application enables users to discover services, schedule appointments, manage bookings, and securely interact with providers, while offering administrators complete control over the platform.

---

## 🚀 Features

### 👤 Customer
- User Registration & Authentication
- Browse available service categories
- Search and filter services
- Book appointments with service providers
- View booking history
- Manage profile information
- Rate and review completed services

### 🛠️ Service Provider
- Register as a service provider
- Manage service offerings
- Accept or reject bookings
- Update availability
- Track service requests


### 👨‍💼 Admin
- Manage users and service providers
- Approve provider registrations
- Monitor bookings
- Platform monitoring and administration

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/feb26Group05/FlexServ.git
```

```bash
cd FlexServ
```

---

## Backend Setup

```bash
cd auth-service
```

Build the project.

```bash
mvn clean install
```

Run the application.

```bash
mvn spring-boot:run
```
---

## Frontend Setup

Navigate to frontend.

```bash
cd frontend
```

Install dependencies.

```bash
npm install
```

Start development server.

```bash
npm start
```

Application will run on

```
http://localhost:5173
```
